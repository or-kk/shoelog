# ShoeLog 개인정보 처리 원칙

최종 갱신일: 2026-09-01

ShoeLog는 러닝화 마일리지 계산에 필요한 최소한의 건강 데이터만 사용하고, 모든 처리를 사용자의 Android 기기 안에서 수행합니다.

## 읽는 데이터

- Health Connect 운동 세션 중 달리기와 트레드밀 기록
- 해당 운동과 같은 데이터 출처·시간 범위의 거리 합계
- 기록 식별자, 시작·종료 시각, 출처 앱, 원본 갱신 시각

경로, 위치, 심박수, 걸음 수, 칼로리, 수면, 체중은 읽거나 요청하지 않습니다.

## 저장하는 데이터

- 사용자가 등록한 러닝화 정보와 선택한 사진의 로컬 URI
- 동기화한 운동의 최소 메타데이터와 거리
- 운동과 러닝화의 배정 관계
- 테마, 동기화 기간, 알림, 샘플 모드 등 앱 설정

이 정보는 Room 데이터베이스와 Preferences DataStore에 저장됩니다. ShoeLog는 자체 서버, 사용자 계정, 광고·분석·오류 수집 SDK를 사용하지 않으며 Android `INTERNET` 권한을 선언하지 않습니다.

## 공유와 백업

ShoeLog는 데이터를 외부 사업자에게 전송하거나 판매하지 않습니다. Android 앱 백업을 비활성화했고 데이터베이스, 설정, 파일을 백업 대상에서 명시적으로 제외했습니다.

사용자가 직접 선택한 사진은 원래 사진 제공자의 저장소에 그대로 있으며 ShoeLog는 그 URI에 대한 접근 권한만 보관합니다.

## 알림

알림은 사용자가 알림 권한과 앱 내 알림 설정을 모두 켠 경우에만 표시합니다. 새 미배정 운동이 있다는 사실만 알리며 운동 시간, 거리, 출처를 포함하지 않습니다. 잠금 화면 공개 수준은 비공개입니다.

## 삭제와 권한 철회

- Health Connect 권한은 Android 설정 또는 ShoeLog 설정 화면에서 언제든 철회할 수 있습니다.
- 샘플 모드를 끄면 `sample:` 식별자를 가진 가상 운동과 음수 ID의 가상 러닝화가 제거됩니다.
- 앱을 삭제하면 Android가 ShoeLog의 로컬 데이터베이스와 설정을 삭제합니다.
- Health Connect 원본이 사라진 운동은 ShoeLog에서 삭제 상태로 표시하고 마일리지 합계에서 제외합니다.

러닝화를 삭제해도 Health Connect 운동 원본은 삭제되지 않으며 ShoeLog 내부의 배정 관계만 제거됩니다.

## 개발·배포 시 주의

실제 건강 데이터, 개인 설정, 데이터베이스, 로그 덤프, 서명키를 Git 저장소나 이슈에 첨부하지 마세요. 문제 재현에는 샘플 모드 또는 완전히 가상인 픽스처만 사용하세요.
