# 갤럭시 실기기 테스트 체크리스트

Samsung Health와 Health Connect가 설치된 실제 갤럭시 기기에서 릴리스 전에 아래 항목을 확인합니다. 테스트 중 생성한 실제 건강 데이터나 화면 캡처는 공개 저장소에 커밋하지 않습니다.

## 사전 준비

- [ ] 갤럭시 워치와 휴대전화의 시각·시간대가 일치한다.
- [ ] Samsung Health와 Health Connect가 최신 상태다.
- [ ] Samsung Health가 운동과 거리를 Health Connect에 쓰도록 허용했다.
- [ ] 워치에서 짧은 야외 달리기 또는 트레드밀 운동을 기록하고 Samsung Health 동기화를 마쳤다.
- [ ] `app-debug.apk`를 설치했다.

## 권한과 동기화

- [ ] 첫 실행에서 권한 거부 시 앱이 종료되지 않고 설정 안내를 보여준다.
- [ ] 운동과 거리 읽기 권한을 허용하면 상태가 즉시 반영된다.
- [ ] `지금 동기화` 후 달리기 기록의 시각·거리·출처가 맞다.
- [ ] 걷기·자전거 등 다른 운동은 나타나지 않는다.
- [ ] 같은 기록을 여러 번 동기화해도 중복되지 않는다.
- [ ] 거리 없는 운동은 표시되지만 러닝화 누적거리에 더해지지 않는다.
- [ ] 지원 기기에서 전체 기록 권한을 허용하면 30일 이전 운동을 읽을 수 있다.
- [ ] 권한을 철회하면 오류 대신 다시 허용하는 방법을 안내한다.

## 러닝화와 마일리지

- [ ] 러닝화 등록·수정·은퇴·삭제가 동작한다.
- [ ] Photo Picker로 고른 사진이 앱 재시작 후에도 보인다.
- [ ] 초기 거리와 배정된 유효 운동 거리의 합이 누적거리와 일치한다.
- [ ] 기본 러닝화가 있으면 새 운동에 자동 배정된다.
- [ ] 러닝화 재배정 시 양쪽 신발의 누적거리가 즉시 바뀐다.
- [ ] 러닝화 삭제 후 운동 기록 자체는 남고 미배정 상태가 된다.
- [ ] 원본에서 삭제된 운동은 누적거리에서 제외된다.

## 샘플 모드와 알림

- [ ] 샘플 모드를 켜면 가상의 러닝화 4개와 운동 5개만 추가된다.
- [ ] 실제 동기화 후에도 샘플 운동이 삭제 상태로 바뀌지 않는다.
- [ ] 샘플 모드를 끄면 가상 데이터만 제거되고 실제 데이터는 남는다.
- [ ] 알림 권한을 거부하면 알림 없이 앱 기능이 정상 동작한다.
- [ ] 알림을 허용하고 새 미배정 운동을 동기화하면 한 번만 알린다.
- [ ] 잠금 화면 알림에 시각·거리·출처가 노출되지 않는다.
- [ ] 알림을 누르면 해당 운동을 배정할 수 있는 화면으로 이동한다.

## 개인정보와 안정성

- [ ] 비행기 모드에서도 저장·조회·샘플 모드가 동작한다.
- [ ] 앱 데이터가 Android 백업 대상에 포함되지 않는다.
- [ ] 앱 로그에 건강 기록 값이나 사진 URI가 출력되지 않는다.
- [ ] 라이트·다크 테마, 글꼴 확대, 화면 회전에서 주요 화면을 사용할 수 있다.
- [ ] 앱을 완전히 종료했다 다시 열어도 데이터와 설정이 유지된다.
